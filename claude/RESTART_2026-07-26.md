## RESUME COMMAND — rerun the ab42 array after power-up

```
cd /home/vi/PycharmProjects/PyGVAMP
# (optional) only rerun the seeds that did NOT complete. To find them:
for s in $(seq -w 0 9); do
  d=/mnt/hdd/experiments/ab42_rev_v1/seed_$s
  grep -qs "PIPELINE COMPLETED" $d/exp_*/logs/log_*.txt 2>/dev/null \
    && echo "seed $s DONE" || echo "seed $s RERUN"
done

# Rerun (full fleet, or replace 0-9 with the comma-list of RERUN seeds):
sbatch --array=0-9%4 \
  --export=ALL,PYGVAMP_SRC_OVERRIDE=/home/vi/PycharmProjects/PyGVAMP \
  cluster_scripts/ab42_rev_v1_array.sh
```

The `PYGVAMP_SRC_OVERRIDE` is MANDATORY — the deployed module lacks the reversible
3-phase code, so the job must run the working-tree code. (Alternative: rebuild the
module: `sudo bash module/install_module.sh --prefix /opt/software/pygvamp/1.0.0
--moduledir /opt/modulefiles --skip-env` — then the override is unnecessary.)
